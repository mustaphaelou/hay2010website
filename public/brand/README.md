# HAY2010 logo — web assets (stopgap)

**Source:** supplied by the owner on 2026-11-08. Original file: `docs/brand/assets/hay2010-logo-source.webp` (500 × 500 transparent WebP, artwork bounds 448 × 335). Exact colours: blue `#3E4D9C`, orange `#E97425`, red `#DE212E`, white `#FFFFFF`.

**Status:** these are derived, trimmed web exports for the brand prototype and early build. They are **not** the production masters.

| File | Size | Use | Status |
|---|---|---|---|
| `hay2010-logo.webp` | 468 × 355 | Header (52 px high), footer on a paper chip, OG/social while the vector is pending | Trimmed full-colour raster; do not upscale beyond 52 px |
| `hay2010-logo-white.webp` | 468 × 355 | One-colour white stencil on ink, when a paper chip is not wanted | Raster approximation; the final one-colour artwork must be drawn in vector |

**Rules**

- Do not recolour, redraw, crop, or “clean up” the badge in code. It is the existing brand mark; a vector redraw is a separate, owner-approved production task.
- Do not upscale the raster. It is usable at 52 px (and 104 px for 2×) but not for Open Graph, print or large-format use.
- Keep the header badge at 52 px high (44 px minimum). Below that `2010.Sarl` is illegible.
- The logo's blue and red are **logo-only**; do not use them as UI colours.
- Never substitute the Porto `ct-logo*.png` demo logo or any “adapted” version of it.
- Written confirmation that SOCIETE HAY 2010 owns the artwork (or holds a licence from the designer) is still required before launch.

See `docs/brand/brand-direction.md` §2.1 and the asset checklist for the vector/variant production plan.
