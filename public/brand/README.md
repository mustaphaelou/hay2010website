**Rules**

- Use the SVG wherever possible. Do not recolour, redraw, crop or “clean up” the badge in code.
- Do not use the raster above 52 px display; it is a fallback, not the master.
- Keep the header badge at 52 px high (44 px minimum). Below that `2010.Sarl` is illegible.
- The logo's blue and red are **logo-only**; do not use them as UI colours.
- Never substitute the Porto `ct-logo*.png` demo logo or any “adapted” version of it.
- Written confirmation that SOCIETE HAY 2010 owns the artwork (or holds a licence from the designer) is still required before launch.
- Favicon: test the full SVG at 32 px; if it is too dense, use a crop of the building + arc + `HAY` (without `2010.Sarl`) at 32 px and a simplified 16 px version.

See `docs/brand/brand-direction.md` §2.1 and the asset checklist for the full production plan.
